EmprendeMap

A digital platform that connects entrepreneurs in El Salvador with property owners who have commercial spaces for rent or sale.

My role

  • Mainly responsible for designing the website pages.
  • Helped organize the visual structure and presentation.
  • Occasionally supported the team with coding.
  • HTML

  • JavaScript
  • PHP
  • MySQL

Read the case study
Problem
Many entrepreneurs struggle to find affordable commercial spaces, and some sell from home because they can’t afford one. At the same time, property owners have empty spaces but can’t find renters.
Solution
Users choose to be an entrepreneur or a property owner. Entrepreneurs explore locations with descriptions, images and prices. Owners publish, edit and delete listings. The platform also gives useful recommendations to both.
Process and result
  • Year 1: initial idea built in a Hackathon with Power Apps.
  • Year 2: grew into a website presented at Expo.
  • Year 3: a website and an application for ExpoTech.
It started as an idea and evolved over three years, which shows creativity and perseverance.

Problem
Teachers with several classes lose time recording attendance by hand. It’s hard to organize the data, track absences and review records.
Solution
Teachers register students, create class lists and mark each student as present, absent or late. The app shows attendance records and summaries for every student.
Goal
